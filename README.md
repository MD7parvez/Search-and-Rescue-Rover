# Search & Rescue Rover

My first Arduino project, built solo. It helped me gain practical experience with basic robotics and remote control.

## Hardware

- **Arduino Uno** — main controller
- **HC-05 Bluetooth module** — wireless remote control
- **Two geared motors with wheels** — drive the rover
- **One servo** — operates a claw/grappler for picking up objects
